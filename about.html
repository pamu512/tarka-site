The mental model

Evaluate first. Everything else is a plane you can switch off.

The canonical decision path is deterministic evaluate: core-api exposes POST /decisions/v1/decisions/evaluate, backed by Rust packs in tarka-core. Every decision writes a receipt you can cite later.

Around that core, each capability is an optional plane with an honest off-switch: graph hops require a configured GRAPH_SERVICE_URL (empty means off — not a degraded sibling identity); Advise requires your own OpenAI-compatible endpoint; enforcement webhooks only fire when a URL and secret are set. Evaluate never waits on graph, and a webhook miss never converts into a block.

Overrides and late labels flow back as Observe drafts — humans Promote through defined gates, and the live pack stays human-owned. The model never Promotes and never demotes.

Quality — two separate loops

Trust is checked, not assumed.

Blind predetermined-N evaluate events

Human-in-the-loop confirmation that the engine does what the packs say — schedulable, skipped only when there's no drift.

Second-human sampling of closed cases

Cases already closed by the first human get a second pair of eyes via /ops/qa. Two loops, deliberately never collapsed.

Security & claim discipline

A claim lock keeps the marketing honest.

The repo ships with a CLAIM_LOCK: buyer-facing copy must match what's actually on master. Fixture holdouts prove wiring, not live tenants. Unknown metrics read null = unknown, never zero-percent theatre.

Security reports follow a published policy: master-only fixes during beta, private disclosure through the maintainers' published channel, automated Dependabot / Trivy / CodeQL scanning. None of that is a SOC 2 attestation — and the docs say so plainly.
